# WikiDéfi

**[Jouer à WikiDéfi](https://wikidefi.auralismc.fr/)**

WikiDéfi est un jeu de culture générale hébergé sur [wikidefi.auralismc.fr](https://wikidefi.auralismc.fr/). À chaque duel, deux sujets sont tirés de Wikipédia. À toi de deviner lequel est le plus ancien.

## Comment jouer

1. Choisis un niveau parmi **Facile**, **Moyen** et **Avancé**.
2. Lis les deux cartes et sélectionne le sujet qui te paraît le plus ancien.
3. Découvre les dates, puis lance la manche suivante. Chaque bonne réponse rapporte des points et prolonge ta série.

Les cartes donnent aussi accès aux articles Wikipédia pour en savoir plus. Ton record est enregistré dans ton navigateur.

## Sous le capot

L’interface arcade est réalisée en HTML, CSS et JavaScript. Un script PHP utilise Groq pour proposer des sujets, et le jeu interroge Wikipédia en français pour retrouver les articles et les images.
